# Mini Football (Browser)

Now with more detailed player visuals and customization options.

What's new
- Multiple hairstyles (short, long, mohawk, afro, bald).
- Boots color per player (renders under shorts).
- Skin tone customization.
- Buttons to customize the player and randomize the opponent's appearance.

How to customize
- Click "Customize Player" and follow the prompts to pick hairstyle, boots color and skin tone.
- Click "Randomize Opponent" to give the opponent a different hairstyle, boots color and skin tone.

All changes are pushed to the add-football-game branch. If you want a nicer UI for customization (modal with selectors and color pickers) I can add that next.
